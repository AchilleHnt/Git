# Formation Git

Ce dépôt est un petit projet pédagogique conçu pour découvrir les bases de Git et la gestion des versions dans un projet HTML/CSS simple.

## Objectif du projet

Le but de ce projet est de montrer, de manière concrète, comment :

- créer un dépôt Git ;
- suivre des fichiers avec `git add` ;
- enregistrer des changements avec des commits ;
- consulter l’état d’un projet avec `git status` ;
- comprendre la logique de versionnage d’un fichier.

## Ce que contient le projet

Le projet est très simple : il contient une page d’introduction HTML avec quelques sections de texte et un fichier CSS pour la mise en forme.

### Fichiers principaux

- `hello.html` : structure de la page HTML ;
- `style.css` : styles visuels appliqués à la page ;
- `README.md` : documentation du projet.

## Description de la page

La page présente une petite mise en page de formation avec :

- un bandeau d’introduction ;
- une section “Description” ;
- une section “Récompenses” ;
- une mise en page minimaliste inspirée d’un exercice d’apprentissage.

## Technologies utilisées

- HTML5
- CSS3
- Git

## Comment ouvrir le projet

Il suffit d’ouvrir le fichier `hello.html` dans un navigateur.

## Exemple de workflow Git

```bash
git status
git add .
git commit -m "Ajout de la page de formation"
```

## À retenir

Ce dépôt est volontairement simple. Son rôle est pédagogique : il permet d’apprendre les notions fondamentales de Git sans se perdre dans un projet trop complexe.

## Description courte

C’est un projet de formation Git, utilisé pour apprendre les bases du versionnage et de la gestion de fichiers dans un mini site web statique.
